# internal

## Overview
Encapsulates private application logic, core domain services, persistence layers, protocol adapters, and infrastructure primitives for the Engram daemon and CLI.

## Subdirectories & Boundaries
- [core](./core/README.md): Domain logic for semantic memory persistence, optimistic concurrency control (OCC), blame tracking, and task state coordination.
- [db](./db/README.md): Type-safe persistence layer generated by `sqlc` from declarative SQL queries and PostgreSQL schemas.
- [mcp](./mcp/README.md): Model Context Protocol (MCP) server implementation exposing agentic tools and SSE streaming endpoints.
- [platform](./platform/README.md): Infrastructure utilities covering database pooling, outbox streaming, auth middleware, and RFC 7807 error mapping.

## Invariants
- Ports & Adapters Architecture: Core domain logic in `internal/core` must remain independent of external transport protocols (`internal/mcp`).
- Internal Encapsulation: Code inside `internal/` cannot be imported outside this repository.
- Outbox Consistency: Core mutations must record events in `engram_events` within the same database transaction.
